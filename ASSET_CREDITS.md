# Image sources

The personalized avatar in `shayan-avatar.png` was generated with the built-in image-generation tool, using the website owner's existing portrait as an identity reference. It is a stylized representation of Syed Shayan Ali Shah, with the requested fuller face and short beard. The original photograph remains in the sidebar.

Generation brief: preserve the same adult man's recognizable identity, wide round cheeks, broad nose, dark brown eyes, thick eyebrows, short wavy black hair, short boxed beard and moustache; slightly chubby physique; sage zip cardigan, off-white shirt, crossed arms and a laptop; front-facing premium 3D character styling; expressive brown eyes; transparent cutout; no text, logos, pedestal, or geometric decoration. A second targeted edit strengthened the avatar styling and enlarged the eyes while preserving the likeness, pose, and outfit.

The original avatar PNG is bundled without image-file alterations. At runtime, a Canvas compositor moves cropped iris imagery inside eyelid masks, with a shaded sclera underneath. The surrounding face never stretches. No external character service or stock subscription is required.
